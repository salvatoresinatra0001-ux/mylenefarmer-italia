# Mylène Farmer Italia — Total Edition V1.0 (LOCAL PREVIEW)

Anteprima locale con nuova homepage, sette sezioni di navigazione e galleria V30.3 enhanced incorporata.

## Provenienza e limiti
- Repository GitHub consultato: salvatoresinatra0001-ux/mylenefarmer-italia, branch main, 17 ottobre 2026.
- Struttura originale verificata: biografia, discografia, ascolta, concerti, media, galleria-hq, archivio-fotografico, fonti, crediti-foto, approfondimento e dataset fotografico.
- Netlify: progetto `mylenefarmer-italia`, deployment attivo verificato. Netlify non fornisce qui un'esportazione dei file del deployment.
- Le pagine editoriali originali non sono state copiate integralmente: le pagine locali contengono rimandi espliciti alle pagine GitHub esistenti.
- La galleria locale deriva dalla preview V30.3 Enhanced, con fotografie esterne Wikimedia Commons; non è interamente offline.
- Selettore trilingue completo è presente nella galleria; la nuova homepage ha termini trilingui ma non tre traduzioni complete.
- Nessuna modifica online o deploy effettuato.

## Avvio
Aprire `index.html` nel browser. Per testare tutte le richieste JSON locali usare `python3 -m http.server 8000` nella cartella.

## Prima del rilascio
Acquisire e confrontare tutti i file del repository, verificare immagini e licenze, consolidare le traduzioni IT/EN/FR, correggere eventuali link e testare su server locale.
