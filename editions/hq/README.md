# Mylène Farmer Italia — Beta Preview 1.1 HQ

A cura di Salvatore Sinatra.

Aprire `index.html` in un browser moderno mentre si è connessi a Internet.

Questa versione è una preview statica senza build step: HTML, CSS e JavaScript sono inclusi nella pagina unica. Le **5 fotografie Full HD** sono referenziate dai file JPEG originali Wikimedia Commons, non dai file locali; la connessione è necessaria. Le 12 schede discografiche sono tipografiche e non contengono copertine JPEG da verificare.

`robots.txt` impedisce l'indicizzazione accidentale di questa preview in caso di deploy di prova. Il file HTML contiene anche `noindex, nofollow`.

Prima di un deployment pubblico, verificare manualmente immagini nel browser, licenze, performance su smartphone, regole di pubblicazione e presenza di tutte le risorse desiderate.

Questa beta non modifica nessun sito attualmente pubblico. Leggere `QUALITY_AUDIT.md` per criteri e provenienze.
