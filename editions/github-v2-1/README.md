## Pagine
- `index.html`: **v2.0 Beta** fornita dall'utente, integrata in **v2.1** (biografia, cronologia, discografia, temi, FAQ, contatti), con hero HQ e collegamento alla galleria.

Sito statico HTML/CSS/JS. Su GitHub Pages: repository `main` dalla cartella `/`.
Su Netlify: nessun build command; publish directory `.`.

Una copia dell'archivio precedente può essere recuperata dal branch di backup creato prima della sostituzione della `main`.

Progetto non ufficiale, non affiliato all'artista, al management o alle etichette discografiche. Le fotografie appartengono ai rispettivi autori.
