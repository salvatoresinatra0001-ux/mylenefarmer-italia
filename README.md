# Mylène Farmer Italia — Édition Totale V1.0

Pacchetto locale unificato. Non è stato eseguito alcun deploy o push.

## Come aprire
Aprire `index.html` nel browser. Per fetch JSON della galleria, usare un server locale (`python3 -m http.server 8000`).

## Provenienza
- `editions/edizione-italiana/`: archivio integrale fornito dall'utente, con contenuti HTML e sorgenti.
- `archivio/`: copia navigabile dell'edizione italiana (schede album incluse).
- `editions/total-preview/`: V1 Total Preview.
- `editions/github-v2-1/`: GitHub V2.1 fornita dall'utente.
- `editions/netlify-v1-1/`: Netlify V1.1 fornita dall'utente.
- `editions/beta/` e `editions/hq/`: ulteriori versioni storiche fornite.
- `galerie/`: galleria della Total Preview, preservata e collegata.

## Limiti
Homepage nuova con selettore IT/EN/FR per gli elementi principali; le pagine archiviate mantengono la lingua e il layout originari. La traduzione integrale di tutti i testi non è ancora completa. La qualità HD, i diritti e la raggiungibilità di tutte le immagini remote richiedono audit individuale. Le versioni storiche sono conservate come archivi separati, non fuse semanticamente riga per riga.

## Distribuzione
Struttura statica compatibile con hosting di sottocartella GitHub Pages e radice Netlify; test di produzione non effettuato.
